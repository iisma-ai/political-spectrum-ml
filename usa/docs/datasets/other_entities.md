# Data sources for other entities

Researched on 2026-11-02 while planning the USA work. Move these to each entity's `docs/datasets/` when that entity is created. European Parliament sources are now in [european_parliament/docs/datasets/sources.md](../../../european_parliament/docs/datasets/sources.md).

| Source | Covers | Status |
|---|---|---|
| [HowTheyVote](https://github.com/HowTheyVote/data) | European Parliament roll calls, open CSV, updated weekly, [official sources](https://howtheyvote.eu/about) | Confirmed; best next entity |
| [VoteWatch data](https://cadmus.eui.eu/handle/1814/74918) | European Parliament 2004 to 2022, EU Council 2009 to 2022 | Confirmed |
| [Bundestag roll calls](https://edoc.unibas.ch/68530/) | Germany, 1949 to 2013 | Confirmed |
| [ParlaMint](https://www.clarin.si/info/parlamint-3-0-parliamentary-corpora-release/) | Speech from 26 parliaments in release 3.0 | Confirmed |
| [ICLMD](https://openscholarship.wustl.edu/data/2) | Metadata on roll calls in national parliaments | Confirmed |
| [Comparative Agendas Project](https://academic.oup.com/book/11237/chapter/159770429) | Topic coding across countries | Page found |
| ParlSpeech V2 | Parliamentary speech | Unverified |
| Comparative Legislators Database | Legislator data | Unverified |

Roll-call use and procedures [vary across countries](https://www.poliscidata.com/insights/923), so the votes recorded differ. Check this before comparing results between entities.
